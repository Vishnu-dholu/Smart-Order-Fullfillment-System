**Provider:** Google Identity (OAuth 2.0) **Flow:** Backend Verification (Frontend sends ID Token -> Backend verifies -> Backend issues JWT) **Library:** `google-api-client`

---

## 1. Overview

The system allows users to log in using their Google account. Instead of creating a new password, the system trusts the **Google ID Token** provided by the frontend.

- **If User Exists:** Logs them in and returns a system JWT.
    
- **If New User:** Automatically registers them with a random username and role `CUSTOMER`, then returns a system JWT.
    

---

## 2. API Endpoint

### 🔵 Google Login

Exchanges a Google ID Token for a System JWT.

- **Endpoint:** `POST /auth/google`
    
- **Access:** Public (`permitAll`)
    

**Request Body:**


```json
{
  "idToken": "eyJhbGciOiJSUzI1NiIsImtpZCI6..." 
}
```

_Note: This token comes from Google's `response.credential` (web) or `id_token` (playground)._

**Response (200 OK):**


```json
{
  "token": "eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJqb2huQGV4YW1wbGUuY29tIiwicm9sZSI6IkNVU1RPTUVSIn0..."
}
```

## 3. Configuration & Scopes

### Required Scopes (Frontend)

To prevent `NullPointerException` on the backend, the frontend **must** request these scopes:

1. `email` (For login ID)
    
2. `profile` (For Name and Picture)
    

### Backend Properties (`application.properties`)

Properties

```
# Google OAuth
# Must match the 'aud' field in the incoming token
google.client.id=YOUR_CLIENT_ID.apps.googleusercontent.com
```

---

## 4. Business Logic (`AuthService.loginWithGoogle`)

1. **Verify:** Uses `GoogleIdTokenVerifier` to check if the token is valid and meant for this app (Audience check).
    
2. **Extract:** Pulls `email` and `name` from the payload.
    
3. **Fallback:** If `name` is null (rare, but possible if scope is missing), falls back to the email prefix (e.g., `john` from `john@gmail.com`).
    
4. **Auto-Register:** * Generates a unique username: `name_randomUUID`.
    
    - Sets a dummy password (user cannot login with password unless they reset it).
        
5. **Issue Token:** Generates a standard system JWT for the user.
