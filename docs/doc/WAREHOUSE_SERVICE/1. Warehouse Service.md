## 1. Overview

The Warehouse Service is a high-performance microservice designed to manage the physical fulfillment network. It tracks **where** items are stored and allows the **Order Service** to intelligently route orders to the nearest facility.

### **Key Responsibilities**

1. **Network Management:** Registering new physical warehouses.
    
2. **Inventory Tracking:** Handling inbound stock updates (Add/Remove items).
    
3. **Smart Allocation:** Providing a real-time list of warehouses that hold a specific product.

## 2. Architecture & Flow

### **Data Model**

The service uses a relational model separating the "Place" (Warehouse) from the "Item" (Stock).

```mermaid
erDiagram
    WAREHOUSES ||--o{ WAREHOUSE_STOCK : "holds"
    
    WAREHOUSES {
        uuid warehouse_id PK
        string name
        string location
        int capacity
    }

    WAREHOUSE_STOCK {
        uuid id PK
        uuid warehouse_id FK
        uuid product_id "Ref to Inventory Svc"
        int quantity
        timestamp updated_at
    }
```

---

### **Smart Query Logic**

When the Order Service asks "Who has Product X?", the Warehouse Service executes an optimized join:

```mermaid
sequenceDiagram
    participant OrderSvc as Order Service
    participant WarehouseSvc as Warehouse Service (Go)
    participant DB as Neon DB

    OrderSvc->>WarehouseSvc: GET /stock/{product_id}
    Note right of OrderSvc: "I need to route Order #123"
    
    WarehouseSvc->>DB: SELECT w.name, w.location, s.quantity <br/>FROM warehouses w JOIN warehouse_stock s...
    DB-->>WarehouseSvc: Result: [ {East Coast, 50}, {West Coast, 10} ]
    
    WarehouseSvc-->>OrderSvc: JSON List of Locations
    Note left of WarehouseSvc: Order Svc now chooses <br/>the closest location.
```

## 3. API Reference

### 🔵 Create Warehouse

**POST** `/warehouses`

```json
{
  "name": "Seattle Fulfillment Center",
  "location": "Seattle, WA",
  "capacity": 20000
}
```

### 🟢 Update Stock (Inbound)

**POST** `/warehouses/:id/stock`


```json
{
  "product_id": "a1b2c3d4-...",
  "quantity": 50
}
```

### 🟣 Check Availability (Smart Query)

**GET** `/stock/:product_id` **Response:**

[
  {
